# Forestry V9 — Manor-Lords-inspired logging pass

## Why V8 was replaced

V8 treated one resource node as one tree that was repeatedly reduced into smaller log pieces. That is visually gamey and does not match the grounded logging rhythm used by Manor Lords.

## V9 flow

- One Wood resource node is presented as a small stand of individual trees.
- Each 5-Wood gather batch corresponds to one physical tree in that stand.
- The worker walks to the exact active tree rather than the abstract node center.
- Work is staged as chopping, a visible fall, then debranching of the full trunk.
- Completing the gather removes that one tree and advances the stand to the next tree.
- Harvested slots remain as stumps, so a forest visibly thins over time.
- The returning Wood gather job is presented as a heavy full-length timber log with a draft ox instead of a floating resource cube.
- Managed saplings regrow the stand using the existing forestry lifecycle.

## Art direction

Trees use taller tapered trunks, visible branching and clustered broadleaf crowns. Near-camera trees receive more branch/crown detail; far stands compress to a cheaper silhouette so regional forests stay affordable.

## Architecture

- Simulation remains authoritative; no Three.js state is persisted.
- Tree slot positions are deterministic renderer-independent projections in `Woodcutting.ts`.
- `Jobs.ts` uses the same active-tree point for navigation that `TreeRenderer.ts` uses for presentation.
- Existing resource quantities and construction costs are preserved.
