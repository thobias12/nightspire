# Architecture refactor V7 — simulation test navigation

V7 is a test-only maintainability refactor. Production source is unchanged.

## Problem

The live Pages `tests/simulation.test.mjs` had grown to roughly 137 KiB / 3,486 lines and contained 178 tests spanning planning, construction, combat, needs, services, production, population, workplaces, households, trade, agriculture, family progression and later raid systems.

That made targeted regression work unnecessarily expensive for humans and ChatGPT sessions even though the runtime architecture itself was already decomposed.

## Structure

`tests/simulation.test.mjs` is now a tiny manifest that imports six domain suites:

- `tests/simulation/planning-construction.test.mjs`
- `tests/simulation/schedule-combat-needs.test.mjs`
- `tests/simulation/services-production-population.test.mjs`
- `tests/simulation/workplaces-households.test.mjs`
- `tests/simulation/live-only-systems.test.mjs`
- `tests/simulation/trade-agriculture-resources.test.mjs`

Shared compiled-game imports and helper functions live in `tests/simulation/fixture.mjs`.

## Guardrails

- All 178 existing simulation tests are preserved with their original bodies and ordering.
- The live-only Pages block remains explicit in `tests/simulation/live-only-systems.test.mjs` so family, settlement progression and later raid coverage are not mixed into `main`-only suites.
- `scripts/test.mjs` still invokes `tests/simulation.test.mjs`; the command surface does not change.
- No files under `src/` are modified.
- The production 80 KiB TypeScript limit and runtime-cycle checks are unchanged.
