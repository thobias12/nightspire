# Architecture refactor — 2026-09-28

The live Pages branch was reorganized without replacing its newer systems or presentation work.

## Problems fixed

- unrelated gameplay domains had accumulated in one flat `src/game/simulation/` directory.
- `WorldState` depended on scheduling behavior for the settler-role type.
- regional navigation duplicated `cellKey` to avoid a runtime import cycle.
- test compilation reused stale `.test-build` output, which could hide deleted/moved module mistakes.
- future ChatGPT sessions had to search large flat folders and historical docs to find ownership.

## Result

- app/model/persistence/runtime/world are explicit.
- construction/jobs/economy/population/combat/progression have separate system folders.
- live-only Family, Construction and TownProgression code is preserved.
- direct imports remain explicit; no barrels were added.
- shared grid primitives are dependency-free.
- CI includes a structural architecture check.
- `docs/AI_NAVIGATION.md` gives future chats a concise ownership map.

The next safe cleanup targets are the oversized Game, HUD and SceneRenderer modules. Split them incrementally when working in those areas rather than rewriting them wholesale.
