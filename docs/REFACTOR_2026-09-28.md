# Architecture refactor — 2026-09-28

This refactor is intentionally behavior-preserving. Its purpose is to make future feature work faster and safer.

## Problems found

- `src/game/simulation/` had become a junk drawer containing unrelated world, combat, economy, population, persistence and construction code.
- `WorldState` imported the settler role type from scheduling behavior, reversing the intended model → systems dependency.
- regional A* duplicated the packed `cellKey` helper to avoid a runtime import cycle.
- the test harness reused `.test-build` without deleting it, so deleted/moved compiled modules could survive between runs and hide refactor mistakes.
- README architecture/product text had drifted behind implemented resource-economy work.
- `Hud.ts`, `SceneRenderer.ts` and `Game.ts` remain oversized hotspots; they are explicitly tracked rather than hidden.

## What changed

- source is grouped by app/model/persistence/runtime/world and feature systems.
- relative imports are direct; no barrel files were introduced.
- `world/Grid.ts` is the dependency-free home for shared grid primitives.
- `SettlerRole` now belongs to the state model.
- clean test compilation is mandatory.
- CI runs a structural dependency check.
- `docs/AI_NAVIGATION.md` gives future ChatGPT sessions a concise change map.

## Next safe decompositions

Split HUD markup/panels, renderer building families and Game placement controllers incrementally, with regression coverage. Do not rewrite those large modules wholesale merely to reduce line count.
