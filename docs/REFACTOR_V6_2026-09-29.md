# Architecture refactor V6 — planning hotkeys and shared field undo

V6 narrows the remaining `Game.ts` browser-orchestration hotspot without changing gameplay behavior.

## Hotkey ownership

Build/planning keyboard shortcuts now live in:

- `app/GameHotkeys.ts` — road/plot/building hotkeys, planning Backspace/Enter controls, road width/curve/snap shortcuts, build rotation and cinematic shortcut.
- `app/InputController.ts` — continuous movement, camera rotation, zoom, Escape and attack input remain unchanged.
- `app/Game.ts` — pointer placement, selection, lifecycle wiring and action dispatch remain.

The split preserves the existing key mappings and uses the same AbortSignal lifetime as the Game instance.

## Duplicate field undo removal

The field-corner undo mutation was duplicated in the right-click and Backspace paths. It now lives once in `app/PlanningOperations.ts` as `undoFieldControlPoint()`.

Both interaction paths call the same Game wrapper, so message text and HUD/ghost refresh behavior remain consistent.

## Guardrails

No simulation, persistence, renderer, save format, building rules, planning geometry, key mapping or medieval HUD presentation changes are intended.
